# NEON RUSH 3D

Бесконечный 3D-раннер в стиле synthwave. Написан на чистом HTML + CSS + JavaScript: без библиотек, без сборки и без интернета.

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari). Работает и на телефоне.

Если хотите поделиться игрой, загрузите папку на любой статический хостинг: GitHub Pages, Netlify, Vercel или itch.io (HTML5-игра, ZIP).

## Управление
| Действие | Клавиатура | Телефон |
|---|---|---|
| Смена полосы | ← → или A D | свайп влево/вправо |
| Прыжок | Пробел, ↑ или W | свайп вверх или тап |
| Быстрое приземление | ↓ или S | свайп вниз |
| Пауза | P или Esc | |
| Звук вкл/выкл | M | кнопка ♪ |

## Игровые механики
- **Блоки**: облетайте их, перепрыгнуть нельзя.
- **Лазерные барьеры** на всю ширину трассы: их можно только перепрыгнуть.
- **Кристаллы** повышают множитель очков (до x10). Каждый пропущенный кристалл его снижает.
- **Щит** (зелёный куб) спасает от одного столкновения.
- **«Впритык!»**: смените полосу в последний момент рядом с блоком и получите бонус.
- **Зоны**: каждые 1600 м меняется мир (Synthwave → Cyber Ocean → Inferno → Toxic → Ultraviolet). За каждую новую зону даётся бонус.
- Скорость постепенно растёт. Рекорд сохраняется в браузере.

## Технологии
- Собственный 3D-движок на Canvas 2D: перспективная проекция, отсечение невидимых граней, плоское освещение, сортировка полигонов по глубине.
- Свечение (bloom) через даунсэмплинг кадра, частицы, тряска камеры, наклон в поворотах, расширение угла обзора на скорости.
- Музыка и звуки синтезируются на лету через WebAudio, без аудиофайлов.
- Качество графики подстраивается само: на слабых устройствах снижается разрешение.
